# Realtime 6008 scripts

Use these scripts from the repository root:

```bash
bash scripts/start_realtime_6008.sh
bash scripts/health_6008.sh
bash scripts/tail_realtime_log.sh
bash scripts/stop_realtime_6008.sh
```

See `docs/runbook.md` for full setup and `README.md` for version boundaries.

Experimental expression controls are off by default in this release.
