# License status

## Project code

OpenVA-Dialogue's source is publicly visible, but the maintainers have **not
yet selected a project-wide license**. No MIT, Apache-2.0, or other blanket
license is granted by this document. In particular, do not interpret a public
GitHub repository or the project's research goals as permission for unrestricted
reuse, commercial use, or redistribution.

The repository contains both project-specific integration changes and inherited
research code, including DyStream and LIA-related rendering utilities. Existing
per-file notices and upstream terms remain relevant. A repository-wide license
must not override third-party rights.

Before a formally licensed release, maintainers need to:

1. Complete the source-provenance and license inventory for inherited files.
2. Confirm permissions for all included third-party source and assets.
3. Select a compatible license for the project's original contributions and
   add its full text, with any necessary exclusions and upstream notices.

## Models and media

Model weights have their own terms, independent of source-code licensing.
Large motion/rendering/TTS weights are downloaded from upstream and are not
mirrored here. The included MediaPipe Face Landmarker task has a separately
documented origin and license in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
The text under `LICENSES/` applies only to the components identified there;
it is **not** the license of the whole repository.

Reference portraits, voice recordings, transcripts, and generated identity-bearing
media require appropriate rights and consent. Access to source or model weights
does not grant rights to someone's likeness or voice.

See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) and the upstream sources
listed there. This status document records unresolved work; it is not a legal
opinion or a certification of full license compliance.
