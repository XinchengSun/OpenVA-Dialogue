# FlashAV2AV 定制说明

FlashAV2AV 支持使用一张正脸图片和一段单人参考声音生成当前会话使用的数字人配置。定制资产只保存在私有运行目录，不属于公开源码。

## 输入要求

### 头像

- 单人、正脸、无遮挡；
- 光线均匀，避免强滤镜和运动模糊；
- 建议至少 `512 × 512`；
- 人脸位于画面中央，头肩完整；
- 确认拥有肖像使用授权。

系统会做人脸检测、裁剪和 DyStream 参考 latent 预处理。若检测不到唯一人脸，任务会失败，不会覆盖当前可用人物。

### 声音

- 推荐 10–20 秒清晰单人语音；
- 无背景音乐、混响和其他说话人；
- 语速、情绪和音高尽量稳定；
- 如果提供参考文本，必须与音频逐字一致；
- 确认拥有声音克隆授权。

上传视频时，系统会先提取音轨，再按相同规则处理。长文件不代表克隆质量更高；系统应选择稳定、干净的有效片段作为提示音频。

## 操作流程

1. 先完成主服务安装和私有 `.env` 配置。
2. 启动服务：

   ```bash
   bash scripts/flashav2av start
   ```

3. 通过本地 SSH 转发或可信 HTTPS 入口打开：

   ```text
   http://127.0.0.1:6008/customize
   ```

4. 上传头像和参考音频或视频。
5. 等页面明确显示处理完成后，再点击启用。
6. 启用会受控重载相关服务；完成前不要重复点击，也不要同时进行演示对话。
7. 返回主页，至少验证三轮问答、一次打断和 Listener 恢复。

## 运行资产

建议通过环境变量把私有资产放在仓库外：

```bash
export FLASHAV2AV_DATA_ROOT=/path/to/flashav2av-data
```

定制作业通常包含：

```text
customizations/<job-id>/
  uploads/        原始上传文件
  processed/      规范化头像与参考 WAV
  artifacts/      motion/renderer/voice 运行资产
  rollback/       启用前配置快照
```

实际目录由私有运行配置决定。不要把 `customizations/`、参考音频、头像、latent 或回滚包提交到 Git。

## 一致性原则

- Listener 和 Speaker 必须使用同一参考人物与同一颜色空间；
- Listener 不使用浏览器循环视频替代模型流；
- 双方静音时仍保持同一条 DyStream recurrent history；
- 用户打断时保留已提交媒体，丢弃尚未提交的旧回复；
- 新人物只有在头像、音色、模型缓存和媒体 smoke 全部成功后才原子启用；
- 任一步失败都继续使用上一个健康人物。

## 启用后的验收

- 页面显示的人物与上传头像一致，无背景叠影；
- 同一回复内和跨句音色稳定；
- Listener → Speaker → Listener 没有明显跳帧；
- 第二轮及后续轮次嘴型仍能正常张合；
- 打断时音画同步结束，没有“无声继续张嘴”；
- `bash scripts/flashav2av status` 仍返回 `DEMO_READY`；
- H.264 + AAC 媒体 smoke 可正常解码。

## 回退

若新人物启用失败：

1. 不删除上一个可用人物及其私有配置；
2. 从该作业的 `rollback/` 恢复启用前配置；
3. 执行：

   ```bash
   bash scripts/flashav2av restart
   bash scripts/flashav2av status
   ```

4. 重新完成多轮、打断、Listener 和媒体解码验收。

不要使用通配符删除运行目录，也不要通过杀死未知 GPU 进程完成回退。

## 安全

- 定制页面默认只允许本机或 SSH 转发访问；
- 不在 URL、日志或 README 中记录访问令牌；
- `.env` 和独立语音服务 env 权限应为 `0600`；
- 公开部署必须使用 HTTPS/WSS、身份验证和访问审计；
- 删除人物前先确认精确作业目录，并优先使用可恢复方式处理。
